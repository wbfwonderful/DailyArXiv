# Daily Papers
The project automatically fetches the latest papers from arXiv based on topics and their keyword variants.

The subheadings represent topics. Each topic searches its name and variants in paper titles or abstracts. See [CONFIGURATION.md](CONFIGURATION.md) for configuration.

Papers are sorted by last update time, with up to 25 query results per topic before subject filtering. First Submitted shows the first submission date; Last Updated shows the latest revision date.

You can click the 'Watch' button to receive daily email notifications.
